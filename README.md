# 🤖 AI Chatbot — Powered by LLaMA 3.3

A conversational AI chatbot built with Python, Streamlit, and Groq API.
Chat with an intelligent AI assistant directly in your browser!

## 🚀 Live Demo
> Run locally using the steps below

## 🛠️ Tech Stack

| Technology | Purpose |
| Python | Core programming language |
| Streamlit | Chat user interface |
| Groq API | AI model (LLaMA 3.3) |
| python-dotenv | Secure API key management |

## 📁 Project Structure
chatbot/
│
├── app.py              ← Streamlit UI
├── chatbot.py          ← Core chatbot logic
├── memory.py           ← Conversation history
├── config.py           ← App settings
├── .env                ← API key (not uploaded)
└── requirements.txt    ← Dependencies

## ✨ Features

- 💬 Real-time AI conversation
- 🧠 Remembers last 10 messages (context memory)
- ⚡ Fast responses using Groq LLaMA 3.3
- 🔐 Secure API key management
- 🎨 Clean and simple chat UI
